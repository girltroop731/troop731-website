# Troop 731 Webmaster — Quick Start

Hi! You're the webmaster for **girltroop731.org**. Here's everything you need to know to keep the site updated.

## How to log in

1. Go to **https://girltroop731.org/admin**
2. Username: `webmaster`
3. Password: (ask Dad — he changed it from the default)
4. The first time you log in you may be prompted to create a new password. Pick something you'll remember and save it!

## What you can update

Once logged in, you'll see a sidebar with sections you can edit:

| Section | What it controls |
|---|---|
| **Dashboard** | Snapshot of the site's stats |
| **Announcements** | Headlines that show on the home page (use these for upcoming campouts, fundraisers, reminders) |
| **Calendar / Events** | Meeting dates, campouts, service projects |
| **About** | Description of the troop, scoutmaster info, charter info |
| **Resources & Links** | Documents like medical forms, handbooks |
| **Past Troop Adventures** | Photos from past events (max 10 in the carousel) |
| **Social Media** | Instagram and Facebook group links |
| **Contact** | Email, meeting time, location |

## Day-to-day tips

- **Adding an announcement?** Keep titles short. Pick a date a few days in the future so it stays visible.
- **Adding a photo?** Square or landscape orientation works best. Keep file size under ~2 MB if you can.
- **Changing meeting time?** Update it under "About" / "Contact" — both pages pull from the same source.
- **Calendar event?** Always set the date AND time. If it's "all day," still pick a start time so it sorts properly.

## What to do if something breaks

1. **Site is down or slow?** Wait 1 minute and try again — it auto-sleeps when no one's visiting and takes a moment to wake up.
2. **You can't log in?** Tell Dad — he can reset your password.
3. **Made a typo or wrong update?** Just edit again — no harm done. Nothing is permanent.
4. **Anything else weird?** Take a screenshot and tell Dad.

## Important DON'Ts

- Don't share the admin password with troop members
- Don't post real names of scouts in announcements (use first names only)
- Don't post photos of scouts that show their faces clearly without parent permission
- Don't change the password without telling Dad

## Important DOs

- Update the calendar at the start of each month
- Add at least one announcement per month so the site looks active
- Refresh the photo carousel after each big event
- Log out when you're done (top right of the admin panel)

Have fun!
